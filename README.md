# 🤖 AI Comment Moderator

An AI-powered web application that classifies comments into **Safe**, **Toxic**, or **Spam** using Machine Learning.

---

## 🚀 Features

- AI Comment Classification
- Safe / Toxic / Spam Detection
- Confidence Score
- Prediction Probability
- User Login & Registration
- Password Hashing
- SQLite Database
- Comment History
- Search & Filter
- Delete Comment
- Clear History
- Export CSV
- Bulk CSV Prediction
- AI Model Retraining
- Interactive Dashboard
- Pie Chart Statistics
- Dark Mode

---

## 🛠 Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- SQLite
- Bootstrap
- HTML
- CSS
- Chart.js
